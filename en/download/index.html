Family Media

Install the Jiaying server on your NAS

The server is required when Family Media reads folders from your NAS. If you only connect to an existing Jellyfin server, you can skip this page.

Current stable release

1.0.0

Platform: Linux AMD64, for NAS devices reporting the x86_64 architecture.

Download Docker image View full release

Download the required files

Docker image archive family-media-server-1.0.0-linux-amd64.tar
Image checksum family-media-server-1.0.0-linux-amd64.tar.sha256
Configuration template config.nas.example.yaml

Check the NAS architecture

Run this command in a NAS terminal:

uname -m

Use the current image only when the result is x86_64. aarch64 and arm64 are not supported yet.

Verify the download

Place the image archive and checksum file in the same directory, then run:

sha256sum -c family-media-server-1.0.0-linux-amd64.tar.sha256

To verify on a Mac, run:

shasum -a 256 -c family-media-server-1.0.0-linux-amd64.tar.sha256

Continue only after the check reports OK.

Import and create the container

  1. Open Docker or Container Manager on the NAS and import the downloaded tar file under Images.
  2. Create config.yaml from the template and update the media location for your NAS.
  3. Create a container and map NAS port 8080 to container port 8080.
  4. Add the four volume mappings below and keep the default image command.
  5. Set the restart policy to unless-stopped and the stop timeout to at least 30 seconds.
NAS media directory/media/libraryRead only
Persistent data/dataRead and write
config.yaml/app/config.yamlRead only
Program directory/opt/family-media/binRead only

Connect Jiaying

After the container starts, open http://your-NAS-local-address:8080/healthz in a browser. When it returns {"status":"ok"}, add the same local NAS address in Jiaying.

Use the server only on your home network.

Do not expose its port directly to the internet. Never post a real server address, password, or token in a public issue.

Future updates

After the first deployment, you can download the standalone server binary and its SHA-256 checksum. Stop the container and verify the new file before replacing the program in the mapped directory. Keep the original media directory and /data.
