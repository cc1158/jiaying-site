Family Media

在 NAS 上安装家映服务端

使用 Family Media 读取 NAS 文件夹时，需要先部署这个服务端。如果你只连接已有的 Jellyfin，可以跳过本页。

当前稳定版本

1.0.0

平台：Linux AMD64，适用于架构显示为 x86_64 的 NAS。

下载 Docker 镜像 查看完整发布页

下载所需文件

Docker 镜像包 family-media-server-1.0.0-linux-amd64.tar
镜像校验文件 family-media-server-1.0.0-linux-amd64.tar.sha256
配置模板 config.nas.example.yaml

确认 NAS 架构

在 NAS 终端执行：

uname -m

只有结果为 x86_64 时才能使用当前镜像。aarch64 或 arm64 暂不支持，请不要强行导入。

校验下载

把镜像包和校验文件放在同一目录，然后执行：

sha256sum -c family-media-server-1.0.0-linux-amd64.tar.sha256

如果在 Mac 上校验，使用：

shasum -a 256 -c family-media-server-1.0.0-linux-amd64.tar.sha256

只有显示 OK 后才继续导入。

导入并创建容器

  1. 打开 NAS 的 Docker 或 Container Manager，在“映像”中导入下载的 tar 文件。
  2. 从配置模板创建 config.yaml，按你的 NAS 路径修改媒体目录。
  3. 创建容器并把 NAS 端口 8080 映射到容器端口 8080。
  4. 按下表添加四个目录映射，启动命令保持镜像默认值。
  5. 将重启策略设为 unless-stopped，停止宽限期设为至少 30 秒。
NAS 媒体目录/media/library只读
持久化数据目录/data读写
config.yaml/app/config.yaml只读
程序目录/opt/family-media/bin只读

连接家映

容器启动后，在浏览器中访问 http://你的NAS局域网地址:8080/healthz。看到 {"status":"ok"} 后，在家映中添加同一个 NAS 局域网地址。

仅限家庭局域网使用。

不要将服务端端口直接暴露到互联网，也不要在公开 Issue 中发布真实服务器地址、密码或 Token。

后续更新

已经完成首次部署的用户，可以从发布页下载 独立服务端程序及其 SHA-256 校验文件。停止容器并校验新文件后，再替换映射目录中的程序；不要删除原来的媒体目录或 /data。
